# SCPI-драйверы для анализаторов спектра и генераторов

Универсальная библиотека на Python для управления измерительными приборами через SCPI-команды. Позволяет автоматизировать радиочастотные измерения, поддерживая разные модели анализаторов спектра и генераторов без изменения основной логики.

Разработано в рамках статьи на Хабре: 
[Измерительные приборы под контролем - универсальный SCPI-драйвер для автоматизации радиоизмерений (Python + Keysight, АКИП, R&S)]
(https://habr.com/ru/users/MaksAnt/).

## Возможности

- Управление анализаторами спектра: АКИП-4212/3, АКИП-4214/2, Keysight N9952A и другими (легко добавить новые).
- Управление генераторами сигналов (по аналогичной схеме).
- Измерение коэффициента шума, коэффициента передачи, мощности в канале.
- Автоматическая калибровка ослабления входного кабеля.
- Сохранение результатов в текстовые и pickle-файлы.

## Требования

- Python 3.11+
- Библиотеки из `requirements.txt`

## Установка

1 Клонируйте репозиторий:

   ```bash
   cd auto_meas_example_v1
   ```

## Быстрый старт
- Перед запуском убедитесь, что приборы доступны по сети (Ethernet) и указанны корректные IP-адреса измерительных приборов в файле scripts/scripts_for_meas.py в строчках:
	g = select_gen_driver('192.168.1.23')
    s = select_spec_driver('192.168.1.24')

### 1. Запуск калибровки кабеля 
- Для запуска калиброки радиочастотного (РЧ) кабеля (измерения ослабления РЧ кабеля) подключите измеряемый РЧ кабель между генератором сигнала и анализатором спектра
- Команда для запуска:
```bash
python -m scripts.scripts_for_meas --calibrate
```
- Измерения будут выполнены на частотах из массива np.arange(950, 2151, 10)
- В завершения будут созданы файлы calib_cables/loss_cableIN.pickle и calib_cables/loss_cableIN.txt.

### 2. Измерение коэффициента шума (КШ)
- Для измерения КШ (в данном случае анализатора спектра) откалиброванный РЧ кабель должен быть подключен между генератором сигнала и анализатором спектра.
- Команда для запуска:
```bash
python -m scripts.scripts_for_meas --nf
```
- Измерения будут выполнены на частотах из массива np.arange(950, 2151, 50)
- Результат измерения КШ сохранится в файл results/nf_meas.txt

## Структура репозитория
drivers/					-	Драйверы приборов: анализаторов спектра, генераторов сигналов, платы изделия (в виде заглушки)
drivers/scpi_device.py		-	Базовый класс для TCP-соединения с приборами
drivers/spec_drivers.py		-	Драйверы для управления анализаторами спектров АКИП-4212/3, АКИП-4214/2 или Keysight N9952A
drivers/gen_drivers.py		-	Драйверы для управления генератором сигнала
drivers/board_drivers.py	-	Управление питанием/настройка исследуемой платы (заглушка)
scripts/scripts_for_meas.py	-	Основные сценарии измерений
calib_cables/				-	Результаты калибровки 
results/					-	Результаты измерений

## Для добавления нового прибора 
1. Создайте новый класс в соответствующем драйвере (например, drivers/spec_drivers.py), унаследуйте от SpecBase.
2. Заполните словарь COMMAND_MAP командами для вашего прибора.
3. При необходимости переопределите методы, отличающиеся по поведению.
4. Добавьте класс в DRIVER_CLASSES и в IDN_MAP.
5. Подробное объяснение архитектуры — в статье на Хабре.
